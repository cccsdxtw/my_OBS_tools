⑥ 聊天回覆

主播用 · 非 OBS

建議用 Restream Chat：TW／YT 等平台授權存在 Restream，平常回覆不用自己換 token，也可一次回兩邊。 OBS 上的⑤聊天室覆蓋仍只負責「顯示」、免發話授權。

沒有 Restream 才用下方本機回覆頁（要自己貼 TW／YT 發話 token，那些會過期）。 回覆相關網址都不要加進 OBS 瀏覽器來源。

預設開 chat.restream.io （用你的 Restream 帳號登入即可）。若你有「Embed in stream」專用網址也可貼上。

自備 token 才需要。可 TW＋YT 一起送，但 token 過期要重貼。

開啟本機回覆頁
為什麼不用一直驗證？
舊版 livestats2 要把 Twitch Access Token 塞進網址，過期就要重授權。 這裡 OBS 顯示用覆蓋改抓公開資料，日常不必再跑 OAuth。 回覆請優先用 Restream（授權由 Restream 維持）；本機回覆頁才需要自己管會過期的發話 token。 ①②③⑤ 右邊網址各自加 OBS 瀏覽器來源即可（⑥ 回覆除外）。
